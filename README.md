Arcade Hub — Minimal Gaming Website

Files created:

- index.html
- styles.css
- script.js
- assets/placeholder.svg

Quick start:

1. Open `index.html` in your browser to run locally.

2. Or run a simple local server (recommended) from the folder:

```bash
# Python 3
python -m http.server 8000

# Then open http://localhost:8000
```

Notes:
- The demo uses a small canvas-based placeholder game. Extend `script.js` to add more games.
- Assets are stored in the `assets/` folder.
